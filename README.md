# Arcane Staff — мод для Minecraft 1.21.4 (Fabric)

## Что делает мод
- **Волшебный посох** с 6 заклинаниями: Огненный луч, Молния, Телепорт, Исцеление, Ледяная волна, Метеор.
  - ПКМ — применить заклинание, клавиша **Z** (или **R**) с посохом в руке — переключить заклинание.
- **Два новых моба** с перерисованными текстурами и оружием в руках, у каждого свои способности:
  - **Кристальный голем** (кристальная булава в руке): «Сокрушающий удар» по площади и «Кристальный панцирь» (стойкость при малом здоровье).
  - **Арканный скелет-маг** (арканный лук): стреляет залпом из 3 стрел, каждый 4-й выстрел — огненный залп из 7; «Мерцание» — отпрыгивает назад, если враг рядом.
  - Не горят на солнце, роняют **Арканный кристалл**. Появляются в мире **во время грозы** («Арканная буря»), в любое время суток.
- **Арканный алтарь**: ПКМ по нему с 5 Арканными кристаллами в руке призывает босса (молнии, портальный вихрь).
- **Два босса.** Перед каждой атакой босс замирает и светится, а на земле растёт **заполненная красная фигура** (круг, линия или сектор);
  когда заливка достигает контура, срабатывает удар. Направление удара фиксируется в начале замаха — автонаводки нет, можно увернуться или перекатиться (X).
  - **Арканный Страж** (рыцарь с Клинком Стража, алтарь: 5 кристаллов): атаки как для мечника — Сокрушающий круг, Рывок, Веер клинка,
    Комбо из трёх ударов, Прыжок с ударом; на 66% и 33% здоровья призывает Кристальных големов.
  - **Архимаг** (маг в мантии, **алтарь Архимага**: 8 кристаллов): держится на дистанции 8–14 блоков, бросает метеоритный дождь, рой самонаводящихся
    сфер, звездопад; вплотную отбрасывает взрывом или телепортируется (телепорт перезаряжается 12 секунд — мечом его достать можно).
    С него выпадают **Посох Архимага** (+50% к урону заклинаний, шанс 35%) и **Мантия Архимага** (перезарядка заклинаний −25%, мана +50% быстрее, шанс 30%).
  - **Метеориты** — настоящие огненные шары (у босса и у посоха игрока): круг на земле заполняется ровно к моменту падения, взрыв выбивает воронку как от TNT
    (`/arcane terrain off` отключает разрушение).
- **RPG-прокачка с тремя классами**: за убийство монстров даётся опыт → уровни (до 15 у каждого класса) → очки навыков.
  Меню навыков — клавиша **K**, класс переключается стрелками **< >** (или клавишами ← →).
  Уровень и очки общие, их можно тратить в любом классе.
  - **Маг**: Сила магии, Быстрая магия, Молния, Телепорт, Исцеление, Ледяная волна, Мудрость (+15% опыта),
    **Метеор** (настоящий огненный шар летит с неба и взрывается как TNT; рельеф ломается при включённом `mobGriefing`).
  - **Мечник** (с мечом в руке): Сила клинка, Железная кожа, Живучесть, Жажда крови,
    **Вихрь клинков [R]** (три вращающихся лезвия, два удара, враги подлетают), **Рывок клинка [Z]** (рывок сквозь врагов),
    **Грозовой клинок** (шанс молнии при ударе).
  - **Лучник** (с луком в руке): Меткость, Лёгкие ноги, Лёгкое падение, Огненные стрелы, Азарт охотника,
    **Прямой полёт** (стрелы без падения, со светящимся следом),
    **Град стрел [R]** (5 залпов подряд, 25 стрел, вращающаяся магическая печать), **Ливень стрел [Z]** (круг на земле, затем 36 стрел с неба).
- - **Уровни у каждого класса отдельно (как в Skyrim)**: опыт получает тот класс, которым убит моб (заклинание/посох — Маг, меч — Мечник, стрела — Лучник).
  У каждого класса свои уровень, опыт и очки навыков (меню K, вкладки `<` `>`).
- **Мана и выносливость**: заклинания тратят ману, а бег, прыжки, перекат и умения мечника и лучника — выносливость.
  Когда выносливость кончается, нельзя прыгать и ходьба замедляется. Полоски и перезарядки R/Z — слева внизу экрана.
- **Перекат (X)**: рывок в направлении движения с короткой неуязвимостью (тратит выносливость).
- **Бой с боссом в стиле Dark Souls**: перед каждой атакой Страж замирает и светится, на земле вспыхивает зона удара,
  через ~0,7 секунды она срабатывает. Атаки: Сокрушающий круг, Рывок, Веер клинка, Метеоритный дождь (метеоры падают вокруг босса
  и **ломают землю**, отключается `/arcane terrain off`), Звездопад. При появлении — крупный заголовок на экране.
- **Свои частицы** (искры, руны, кристаллические блики, метеоритное пламя, золотая пыль) с собственными текстурами.
- **Достижения**: «Уничтожитель чанков» (метеор по 5+ монстрам), «Убийца Стража», «Ритуал призыва»,
  «Мастер трёх путей», «Легенда арканы» (30 уровень), «Небо в стрелах», «Танцор клинков».
- Прокачка сохраняется в мире и не пропадает после смерти.

## Оформление
- **Мобы**: броня, корона и руны нарисованы прямо на их текстурах (`textures/entity/`), ванильной брони на них нет.
- **Оружие в 3D**: Арканный посох, Клинок Стража, Кристальная булава — объёмные модели из кубиков (`models/item/*.json`).
  У скелета лук — настоящий лук с «Арканным» внешним видом.
- Все умения сопровождаются анимацией из частиц (печати, спирали, волны).

## Как получить предметы
- Крафт посоха: 3 Арканных кристалла + 2 палки (схема: `CC_ / CS_ / S__`, C — кристалл, S — палка).
- Крафт алтаря: 5 Арканных кристаллов + 4 обсидиана (схема: `CCC / COC / OOO`, C — кристалл, O — обсидиан).
- Крафт алтаря Архимага: `CAC / AOA / OOO` (C — Арканный кристалл, A — аметистовый осколок, O — обсидиан).
- Мантия Архимага выдаётся только с босса; для проверки: `/give @s leather_chestplate[dyed_color={rgb:2767016,show_in_tooltip:false},item_model="arcane:archmage_robe",enchantment_glint_override=true]`.
- Команды (работают без читов):
  - `/arcane staff` — выдать посох;
  - `/arcane xp 100` — добавить опыт магии (для показа прокачки);
  - `/arcane reset` — сбросить прокачку;
  - `/arcane boss` (Страж) и `/arcane boss archmage` — призвать босса перед собой (без алтаря);
  - `/arcane xp mage 500` (или `sword`, `archer`) — опыт одному классу; `/arcane xp 500` — всем трём;
  - `/arcane terrain off` — метеоры босса не ломают землю.
- Клинок Стража и Кристальная булава — вкладка «Инструменты» (творческий режим).
- Яйца призыва мобов и босса — в творческом режиме, вкладка «Яйца призыва».

## Что нужно, чтобы запустить в игре
1. Minecraft Java **1.21.4**.
2. Fabric Loader для 1.21.4 (https://fabricmc.net/use/installer/).
3. Fabric API для 1.21.4 (Modrinth или CurseForge) — положить в папку `mods`.
4. Файл мода `arcane-staff-1.0.0.jar` — тоже в папку `mods`.

## Как собрать мод (получить .jar)
### Вариант 1. Через GitHub, ничего не устанавливая
1. Создайте репозиторий на github.com и загрузите в него все файлы этого проекта (Add file → Upload files). Папка `.github` должна загрузиться вместе с остальными.
2. Откройте вкладку **Actions** → запустится сборка `build` (или нажмите Run workflow).
3. Через 3–5 минут откройте завершённую сборку и скачайте **Artifacts → arcane-staff-mod**. Внутри будет `arcane-staff-1.0.0.jar`.

### Вариант 2. На своём компьютере
1. Установите Java 21 (например, Temurin 21).
2. В папке проекта выполните: `gradlew build` (Windows: `gradlew.bat build`).
3. Готовый файл: `build/libs/arcane-staff-1.0.0.jar` (файл с `-sources` в конце не нужен).

## Сценарий показа преподавателю (3–4 минуты)
1. Создать мир в творческом режиме, выполнить `/arcane staff` и `/arcane xp 1300`.
2. Показать посох: ПКМ — огненный луч; **Z** — переключить заклинание (молния, телепорт, ледяная волна, метеор).
3. Вкладка «Яйца призыва» → призвать Кристального голема и Арканного скелета (светящаяся броня, частицы).
4. Нажать **K** → показать древо навыков, стрелками `<` `>` переключить классы Маг / Мечник / Лучник, вложить очки.
5. Взять меч: **R** — вихрь клинков, **Z** — рывок. Взять лук: **R** — град стрел, **Z** — ливень стрел.
6. Поставить Арканный алтарь (вкладка «Функциональные блоки»), ПКМ с 5 кристаллами — призыв босса.
7. Победить босса, показать достижения (клавиша L).

## Структура кода
- `arcane/data/Fx.java` — эффекты из частиц; `arcane/item/` — посох и заклинания; `arcane/block/` — алтарь; `arcane/entity/` — мобы; `arcane/data/` — прокачка, навыки, способности классов, достижения;
- `arcane/net/` — обмен данными клиент ↔ сервер; `arcane/client/` — окно навыков и отрисовка мобов;
- `src/main/resources/` — тексты (ru/en), модели, текстуры, рецепт, добыча с мобов.
